# Sales-Analysis-using-Excel-Rofiat


About the Project

This project analyses sales data using Microsoft Excel to understand revenue performance and sales trends.

Key Metrics

Total Revenue,Total Orders, Total Quantity Sold, Average Order Value, Revenue by Month, Region, Product Category, and Sales Channel,Top 5 Products by Revenue.

Tools Used:Microsoft Excel

Objective:To turn sales data into meaningful insights that support better business decisions.

This project demonstrates practical skills in Excel-based data analysis, KPI calculation, data summarisation, and visualisation. It showcases how raw sales data can be transformed into actionable business insights.
